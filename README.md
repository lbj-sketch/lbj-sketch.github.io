# 个人网站

一个零依赖的静态个人网站：明暗双主题、响应式、滚动动画。
**所有个人信息集中在 `data.js` 一个文件里**，修改它即可，无需碰其他代码。

## 启动

```
双击 run.bat
```

或命令行：

```bash
cd personal_website
python -m http.server 8090 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:8090

## 如何填写你的信息

编辑 [data.js](data.js)，把占位内容替换为真实信息（文件内有中文注释）：

| 字段 | 说明 |
|---|---|
| `name` / `title` / `tagline` | 首屏姓名、头衔、一句话简介 |
| `avatarUrl` | 头像图片（可选）：把图片放进本目录（如 `images/me.jpg`）后填相对地址；不填则显示 `avatarText` 文字头像 |
| `location` | 所在地（不填隐藏） |
| `about` | 自我介绍，字符串数组，每项一段 |
| `skills` | 技能列表，`level` 为 0~100 控制进度条 |
| `experience` | 经历时间线：时间段 / 机构 / 角色 / 描述 |
| `projects` | 项目卡片：名称 / 简介 / 标签 / 链接（可选） |
| `contact` | 邮箱 / 微信 / GitHub / 博客，**留空的项自动隐藏** |
| `footer` | 页脚文字 |

## 文件结构

```
personal_website/
├── data.js      # ★ 个人信息配置（唯一需要修改的文件）
├── index.html   # 页面骨架
├── style.css    # 样式（明暗双主题CSS变量）
├── app.js       # 渲染逻辑（读取SITE对象填充页面）
└── run.bat      # 一键启动
```

## 特性

- 明暗主题切换（跟随系统偏好，手动切换后记忆在浏览器）
- 滚动渐入动画、技能条动画（尊重系统"减少动态效果"设置）
- 响应式布局（手机端自动收起导航）
- 空板块自动隐藏（如未填联系方式，整个"联系我"板块不显示）
- 无任何外部依赖，完全离线可用
